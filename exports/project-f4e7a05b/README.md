> Generated by ForgeOS Multi-Agent Autonomous Software Factory
> Requirement: "Build a high-performance inventory manager with PostgreSQL and Redis"

## System Overview
- **Architecture**: Modular Monolith / Event-Driven Services
- **Database**: PostgreSQL with Prisma ORM
- **Backend**: Fastify TypeScript REST API
- **Frontend**: Next.js React with Tailwind Design System

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Setup Database Schema
npx prisma generate
npx prisma db push

# 3. Start Backend Server
npm run dev
```
